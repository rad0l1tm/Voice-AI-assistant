# Голосовой ИИ ассистент (Alpha версия)

Локальный голосовой ассистент на русском языке: wake-word активация, распознавание речи, локальная LLM, синтез речи с возможностью перебить ответ, плюс управление приложениями, чтение файлов и экрана голосом. Всё работает офлайн, без обращения к облачным API во время работы.

## Возможности

- **Пробуждение по ключевой фразе** — локальная модель на базе heed-wakeword, ничего не уходит в сеть на этапе распознавания.
- **Распознавание речи (STT)** — sherpa-onnx + GigaAM v2 (русский), с VAD и подавлением «залипаний».
- **Локальная LLM** — Qwen через `llama.cpp`.
- **Синтез речи (TTS)** — Silero (русский).
- **Прерывание озвучки (барж-ин)** — повторное обращение по ключевой фразе во время ответа останавливает воспроизведение и сразу слушает следующую команду. Дорабатывается.
- **Управление приложениями** — голосовое меню установленных программ, запоминание «номер → приложение», открытие и закрытие по имени.
- **Чтение текста с экрана (OCR)** — скриншот + Tesseract, можно попросить как краткий пересказ через LLM, так и дословное чтение.
- **Автоустановка Python-зависимостей** — отсутствующие пакеты подтягиваются через pip при первом запуске.
- **Автонастройка wake-word модели** — если модели нет, при старте запускается интерактивная запись и обучение через `heed-wakeword`.

## Требования

### Железо / память

Рассчитан на то, чтобы работать в пределах **7–8 ГБ ОЗУ** (жёсткий потолок — 10 ГБ) при постоянной работе. Приблизительное распределение:

| Компонент | ~RAM |
|---|---|
| LLM (Qwen, Q4, контекст 4096) | ~3 ГБ |
| STT (GigaAM v2, int8) | ~0.3–0.5 ГБ |
| TTS (Silero) | ~0.1–0.2 ГБ |
| Wake-word + VAD | десятки МБ |
| Python/torch/onnxruntime оверхед | ~0.5 ГБ |
| **Итого (постоянно)** | **~4.5 ГБ** |

OCR (Tesseract) — отдельный короткоживущий процесс, в постоянный бюджет не входит.

### Python-зависимости

Устанавливаются автоматически при первом запуске (см. блок `ensure_dependencies()` в начале скрипта): `torch`, `numpy`, `onnxruntime`, `sounddevice`, `pymorphy3`, `vosk`, `piper-tts`, `sherpa-onnx`, `rapidfuzz`, `llama-cpp-python`, `silero`, `num2words`, `heed-wakeword`.

### Системные зависимости (ставятся вручную)

Нужны для голосовых команд управления приложениями, чтения экрана и выбора проводника:

```bash
# меню приложений (нужен хотя бы один)
sudo apt install wofi
# или: rofi, bemenu

# трекинг окон для закрытия приложений — для не-Hyprland окружений
sudo apt install wmctrl
# Hyprland (hyprctl) и Sway (swaymsg) уже есть в составе DE

# захват экрана (нужен хотя бы один)
sudo apt install grim
# или: scrot, imagemagick (import) — для X11

# OCR
sudo apt install tesseract-ocr tesseract-ocr-rus

# открытие системного файлового менеджера как визуального сопровождения
sudo apt install xdg-utils
```

Если каких-то инструментов нет — соответствующая возможность отключается с понятным предупреждением в лог при старте, остальной ассистент продолжает работать.

### Модели

Не входят в репозиторий (слишком большие для git) — скачиваются/обучаются отдельно:

- **LLM**: GGUF-файл Qwen, путь задан в коде (`Qwen3.5-4B-Q4_K_M.gguf`).
- **STT**: GigaAM v2 (int8, ONNX) — [sherpa-onnx модели](https://github.com/k2-fsa/sherpa-onnx).
- **Wake-word**: обучается автоматически при первом запуске через `heed-wakeword` (голосовая запись положительных/отрицательных образцов), либо заранее — см. документацию [heed-wakeword](https://github.com/AndreiBulzan/heed-wakeword).

## Установка и запуск

```bash
git clone <repo_url>
cd <repo_url>
python3 -m voice_assistant
```

При первом запуске:
1. Автоматически доустановятся недостающие Python-пакеты (опционально).
2. Если wake-word модели нет — начнётся интерактивная запись фразы пробуждения (нужен микрофон и терминал). Если текущая модель не устраивает, можно удалить папку myword в директории проекта и пройти процесс записи с начала.
3. Дальше — обычная работа: скажите ключевую фразу, дождитесь приветствия, произносите команды.

## Голосовые команды

| Команда | Что делает |
|---|---|
| «\<ключевая фраза\>» | Пробуждение, начало прослушивания команды |
| «заверши работу» | Завершение сессии ассистента |
| «открой меню» | Показывает пронумерованный список установленных приложений |
| «закрой меню» | Закрывает меню |
| «запомни номер \<N\> \<имя\>» | Привязывает голосовое имя к приложению №N из меню |
| «перечисли приложения» | Голосом зачитывает список запомненных приложений |
| «открой \<имя\>» | Запускает приложение |
| «закрой \<имя\>» | Закрывает приложение, открытое ассистентом |
| «начни диалог» / «заверши диалог» | Включает/выключает режим свободного общения с LLM |
| «что на экране» | OCR экрана + краткий пересказ через LLM |
| «прочитай экран» | OCR экрана, дословное чтение |

## Известные ограничения
- **Работает только на Linux.** Доработка кроссплатформенности рассматривается в качестве будущих обновлений.
- **Барж-ин без AEC.** Прерывание озвучки повторным обращением не использует аппаратное/программное подавление эха — возможны ложные срабатывания, если голос TTS созвучен с ключевой фразой. Отключается флагом `ENABLE_BARGE_IN = False`.
- **Закрытие окон вне Hyprland/Sway/X11.** На «чистом» Wayland-окружении без wmctrl-совместимого XWayland-фолбэка (например GNOME/KDE Wayland без доп. инструментов) закрытие уже открытых/single-instance-приложений (snap-пакеты, Firefox/Chrome при уже открытом окне) может не работать.
- **Распознавание имён файлов/папок** — нечёткое сопоставление с транслитерацией английских названий, не гарантирует 100% точность на сильно искажённых STT-расшифровках.
